
# React + Vite

# TL;DR
This is a playground repo for nailing down React fundamentals.  
Every commit maps to a specific concept. The full list of topics is below.  
🔗 **Live demo:** [Click to watch live](https://shatskisdimka.github.io/todo-react)

---

## 📚 What's inside

Just a simple todo app that covers the whole React journey — no magic, no over-engineering.

- [x] React from zero for beginners: what it is, why it matters
- [x] Create a React project with Vite: setup, config, and project structure
- [x] JSX in depth: syntax quirks, conditional rendering, lists
- [x] Functional components: breaking UIs into reusable pieces
- [x] Props & children: passing data and composing components
- [x] Events: clicks, input handling, form submissions (`onClick`, `onChange`)
- [x] State with `useState`: adding and updating data in practice
- [x] `useEffect` and component lifecycle: syncing with `localStorage`, filtering tasks
- [x] Controlled vs uncontrolled components: `useRef` and direct DOM access
- [x] Optimizing React: `memo`, `useCallback`, `useMemo` — when and why
- [x] Context API & `useContext`: avoiding prop drilling (needs a revisit)
- [x] Custom hooks: extracting reusable logic
- [ ] Forms in React: managing inputs and basic validation without third-party libs
- [x] APIs in React: `fetch`, `json-server` — GET, POST, DELETE, PATCH
- [ ] Routing without libraries: building page transitions by hand
- [ ] Styling: CSS, SCSS, CSS Modules (no Tailwind, no CSS-in-JS)
- [ ] Animations without libraries: smooth CSS transitions driven by state
- [x] Structuring a React app: Feature-Sliced Design approach
- [x] State management without Redux: `useReducer`, `useState`, `useContext`
- [ ] Security basics: XSS protection, handling sensitive data, search highlight
- [ ] Testing & debugging: React DevTools in action
- [ ] Deploying a React app to GitHub Pages

> 🧠 Most topics are checked because this is a living lab — the unchecked ones are either in progress or scheduled next.
